# CNNDetection: CNN-Based Fake Image Detection

## Short method explanation

**CNNDetection** is a real-vs-fake image detector from the paper **“CNN-generated images are surprisingly easy to spot... for now”** by Wang et al., CVPR 2020.

The method trains a standard CNN classifier to distinguish real images from images generated by **ProGAN**. The main finding is that a detector trained on one generator can generalize to many other CNN-generated image types, including StyleGAN, BigGAN, CycleGAN, StarGAN, GauGAN, CRN, IMLE, super-resolution outputs, low-light enhancement outputs, and DeepFakes.

The released implementation uses a **ResNet-50** classifier initialized from ImageNet pretraining. The final classification layer is replaced with a binary real/fake head. In the original CNNDetection training code, the optimizer is applied to all model parameters, so the ResNet backbone is fine-tuned rather than frozen.

## Pipeline

Given an input image:

1. Resize the image.
2. Apply optional Gaussian blur and JPEG augmentation.
3. Crop the image.
4. Apply random horizontal flip during training.
5. Normalize using ImageNet statistics.
6. Feed the image into a ResNet-50 binary classifier.
7. Output a real/fake prediction score.

The detector is trained as a binary classifier with real images as class `0` and generated images as class `1`.

## Training dataset

CNNDetection trains on a **ProGAN real-vs-fake dataset**.

The training set contains real LSUN images and ProGAN-generated images from **20 LSUN object categories**.

| Split | Source | Description |
|---|---|---|
| Real | LSUN | Real images from 20 object categories |
| Fake | ProGAN | ProGAN-generated images from the same 20 object categories |
| Task | Binary classification | Real vs fake |

The key design choice is that the detector is trained on only **one generator family**, ProGAN, and then evaluated on many unseen generator families.

## Test datasets

The official test set contains images from several CNN-based synthesis algorithms. Each dataset follows a binary structure with real images in `0_real` and fake images in `1_fake`.

| Test source | Type |
|---|---|
| ProGAN | GAN |
| StyleGAN | GAN |
| StyleGAN2 | GAN |
| BigGAN | GAN |
| CycleGAN | Image-to-image translation |
| StarGAN | Image-to-image translation |
| GauGAN | Semantic image synthesis |
| CRN | Cascaded refinement network |
| IMLE | Implicit maximum likelihood estimation |
| SITD | Low-light enhancement / seeing in the dark |
| SAN | Super-resolution |
| DeepFake | Face manipulation |
| WhichFaceIsReal | GAN face images |

## Augmentation details

CNNDetection uses low-level augmentation to improve generalization. The most important augmentations are **Gaussian blur** and **JPEG compression**.

The commonly used robust model, **Blur+JPEG(0.5)**, uses the following settings:

| Component | Setting |
|---|---|
| Resize | `loadSize = 256` |
| Crop | `cropSize = 224` |
| Crop type | Random crop during training, center crop during testing |
| Horizontal flip | Random horizontal flip during training |
| Gaussian blur probability | `blur_prob = 0.5` |
| Gaussian blur sigma | sampled from `blur_sig = 0.0,3.0` |
| JPEG probability | `jpg_prob = 0.5` |
| JPEG backend | randomly selected from `cv2,pil` |
| JPEG quality | sampled from `jpg_qual = 30,100` |
| Normalization | ImageNet mean and standard deviation |

## Performance tables

### Main result

| Training generator | Test generators | Main finding |
|---|---|---|
| ProGAN only | Multiple unseen CNN-based generators | Strong cross-generator generalization |

CNNDetection shows that a detector trained only on ProGAN can detect many other CNN-generated images. This suggests that many CNN-based image generators share detectable artifacts.

### Generator coverage

| Category | Examples | CNNDetection behavior |
|---|---|---|
| GANs similar to training domain | ProGAN, StyleGAN, StyleGAN2, BigGAN | Strong performance |
| Image-to-image translation | CycleGAN, StarGAN, GauGAN | Good cross-generator transfer |
| Other CNN synthesis tasks | CRN, IMLE, SITD, SAN | Often above chance |
| Face manipulation | DeepFake, WhichFaceIsReal | Detectable but domain-dependent |

## Core novelties

### 1. Generalization from one generator

The main novelty is showing that a detector trained only on **ProGAN** can generalize to many other CNN-generated images.

### 2. Standard CNN as a strong forensic baseline

The method shows that a conventional **ImageNet-pretrained ResNet-50** can be a strong fake-image detector when trained with suitable preprocessing and augmentation.

### 3. Blur and JPEG augmentation for generalization

The paper highlights that **Gaussian blur** and **JPEG compression** improve cross-generator generalization and robustness to low-level image changes.

### 4. Evidence for shared CNN artifacts

The results suggest that many CNN-based generators leave common detectable artifacts, possibly related to convolutional synthesis, upsampling, normalization, or other architectural biases.

## Comparison to CLIPDetection

| Aspect | CNNDetection | CLIPDetection |
|---|---|---|
| Backbone | ImageNet-pretrained ResNet-50 | CLIP visual encoder, often ViT-L/14 |
| Training protocol | Fine-tunes ResNet on ProGAN real/fake images | Freezes CLIP and trains only a linear head |
| Training data | ProGAN vs LSUN real images | Same CNNDetection ProGAN training data |
| Augmentation | Blur + JPEG augmentation | Similar CNNDetection-style blur + JPEG augmentation |
| Main strength | Strong generalization across many CNN/GAN generators | Better generalization to diffusion/autoregressive generators |

## Summary

CNNDetection is a foundational fake-image detection baseline. It trains an ImageNet-pretrained ResNet-50 on ProGAN real/fake images and shows strong transfer to many other CNN-generated image types. Its main practical recipe is simple: train on ProGAN, use a standard binary CNN classifier, and apply blur/JPEG augmentation to improve generalization.
